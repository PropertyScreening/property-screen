GITHUB UPDATE
1. Extract this ZIP.
2. Open https://github.com/PropertyScreening/property-screen
3. Choose Add file > Upload files.
4. Upload ONLY these three files to the repository root:
   - index.html
   - styles.css
   - script.js
5. Replace the existing versions of those three files.
6. Leave all other files in the repository untouched. In particular, do not delete or re-upload the MP4, VTT captions, poster, GIF, logo files, images, or separate service pages.
7. Commit to main with message:
   V11 - Add cinematic kinetic typography and 3D motion poster visuals
8. After the Pages deployment finishes, open the site and press Ctrl+Shift+R.
